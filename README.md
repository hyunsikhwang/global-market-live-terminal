# 🌎 글로벌 주가지수 대시보드 (Global Market Index Dashboard)

실시간 전 세계 주요 주가지수의 상태와 차트를 한눈에 살펴보고 추적할 수 있는 프리미엄 풀스택 대시보드 웹 애플리케이션입니다.

한국, 미국, 아시아, 유럽 등 글로벌 금융 중심지 마켓의 실시간 운영 시간과 공휴일을 지능적으로 계산하며, 투자 환경에 따른 유연한 시각적 도구를 함께 제공합니다.

---

## ✨ 핵심 기능

### 1. 지능형 실시간 마켓 상태 통합 판별 엔진
- **마켓 시간 계산**: 각 지수의 현지 타임존을 기반으로 실거래 세션 시간(예: 한국 09:00 ~ 15:30, 미국 09:30 ~ 16:00 등)을 실시간으로 추적하여 `개장(OPEN)`과 `휴장(CLOSED)` 상태를 명확히 표시합니다.
- **주말 및 지능형 공휴일 처리**: 주말 휴장뿐만 아니라 대한민국 부처님오신날 대체공휴일, 미국의 메모리얼 데이(Memorial Day), 영국의 스프링 뱅크 훌리데이(Spring Bank Holiday) 등 각 국가 시장별 2026년 공휴일 일정을 완벽하게 인지하고 판단합니다.
- **다음 개장 일시 추적**: 현재 마켓이 휴장 상태일 때, 가장 가까운 다음 개장 예상 시간을 자동으로 연산하여 화면에 표시합니다.

### 2. 고도로 정밀한 시각화 차트 (SVG Index Charts)
- **현재 시점 맞춤형 실시간 차트 드로잉**:
  - **개장 중 (OPEN)**: 차트가 오른쪽 끝까지 억지로 확장되지 않고, **장 시작 시간부터 현재 시각까지 흘러온 부분 연계 좌표까지만** 동적으로 그려집니다. 빈자리는 전체 세션 시간을 가늠할 수 있게 유지되어 오해 없는 정확한 진행 상황을 알 수 있습니다.
  - **휴장 중 (CLOSED)**: 세션 전체 영역(장시작-장종료)에 대한 하루 등락 과정이 고르게 꽉 차서 표현됩니다.
- **아름다운 그라데이션 영역 뷰**: 주가의 오르내림에 맞춰 상승/하락 컬러의 선과 세련된 그라데이션 채우기(Area Fill)가 다이내믹하게 동기화됩니다.
- **인터랙티브 크로스헤어 툴팁**: 메인 빅 차트 위로 마우스를 호버하면 해당 시간대의 가격 및 등락을 시간 역추적 방식으로 정밀하게 추적하는 호버 커서와 레이블이 반응형으로 나타납니다.

### 3. 상태 기반 지능형 지수 정렬 (Status-driven Sorting)
- 투자자가 가장 중요하게 들여다봐야 할 정보를 선별해 정렬 구조를 갖추었습니다:
  1. **개장 중인 지수(OPEN)** 가 최우선으로 리스트 상단에 배치됩니다.
  2. 개장 중인 마켓들은 **현재 로컬 시간 기준 가장 먼저 개장한 순서**로 정렬됩니다.
  3. 휴장 중인 마켓들은 **다음 개장 시간이 가장 빠르게 다가오는 순서**로 정렬되어 글로벌 마켓 릴레이를 흐름에 맞게 파악할 수 있습니다.

### 4. 커스텀 컬러 스키마 토글 기능
- 거래 환경 또는 국가별 취향에 맞추어 주가 오르내림 색상을 손쉽게 바꿀 수 있습니다.
  - **KR 모드**: 대한민국 정서에 맞춘 **상승(빨간색 🔴)** / **하락(파란색 🔵)**
  - **Global 스탠다드 모드**: 서구권 및 글로벌 투자에 최적화된 **상승(초록색 🟢)** / **하락(빨간색 🔴)**

### 5. 다차원 검색 및 필터링
- **대륙별 탭**: 전체(ALL), 한국(KOREA), 아시아(ASIA), 아메리카(AMERICAS), 유럽(EUROPE)을 한 번의 클릭으로 신속하게 필터링합니다.
- **통합 스마트 검색**: 지수 기호(id), 영문 정식 명칭, 익숙한 한글 정식 지수명(예: 코스피, 나스닥, 가권 등) 중 어느 것을 입력해도 원활하게 필터링 매핑됩니다.

## 🛠 기술 스택

### Frontend
- **React 18**: 컴포넌트 기반 UI 개발 및 반응형 상태 관리
- **TypeScript**: 모든 데이터 타입의 유효성을 보장하는 안전한 정적 타입 설계
- **Tailwind CSS**: 눈이 편안한 다크 슬레이트 룩앤필 및 고대비 모던 웹 인터페이스 구축
- **Lucide React**: 간결하고 신뢰성 높은 반응형 벡터 아이콘 시스템

### Backend (Node.js & Express API Wrapper)
- **Express**: 가볍고 고성능인 RESTful API 라우터 구축
- **Intl DateTime Tools**: 글로벌 타임존 계산 및 날짜 포매틱을 기본 내장 캘린더 엔진화
- **실시간 주가 생성기**: 시장 흐름에 맞춘 변동성 워킹 알고리즘 점진 보정 반영

## 📂 프로젝트 구조

```bash
├── src/
│   ├── components/       # 세부 모듈용 서브 컴포넌트 폴더
│   ├── types.ts          # 주가지수, 이력 히스토리에 대한 공통 TypeScript 인터페이스
│   ├── App.tsx           # 메인 대시보드 뷰 및 핵심 상태 관리 레이아웃
│   ├── main.tsx          # 클라이언트 엔트리 포인트
│   └── index.css         # 글로벌 CSS 및 Tailwind 테마 선언 파일
├── server.ts             # Express & Vite 융합형 full-stack 개발/배포 서버
├── package.json          # 패키지 설정, 의존성 라이브러리 목록 및 실행 스크립트
└── README.md             # 프로젝트 소개 및 매뉴얼 문서 (KOREAN)
```

## 🚀 개발 환경에서 구동하기

### 1. 패키지 의존성 설치
```bash
npm install
```

### 2. 개발 모드 서버 실행
```bash
npm run dev
```
- 서버가 실행되면 [http://localhost:3000](http://localhost:3000) 포트를 통해 정교하게 연동된 실시간 대시보드를 바로 탐색하실 수 있습니다.

### 3. 프로덕션 빌드 및 실행
```bash
# 프로덕션 번들 빌드
npm run build

# 실제 상용용 시작
npm start
```

## 🎯 특징적인 디자인 요소
- **차분하고 고급스러운 Dark Slate Theme**: 눈의 피로를 최소화하는 다크 네이비와 차콜 색상을 메인 배경으로 차용하여 어두운 조명 아래에서도 높은 가독성을 유도합니다.
- **심리스 애니메이션 피드백**: 마켓 리스트 검색, 테마 토글, 마우스 무브 등 각 미이크로 인터랙션 단계를 부드러운 트랜지션 연출로 묶어 높은 수준의 프론트엔드 완성도를 지향합니다.
- **자동 갱신 타이머**: 우상단 원형 프로그레스 형태의 시간 인디케이터가 자동으로 60초마다 시계방향으로 줄어들며, '0'이 되는 즉시 백엔드로부터 새로운 주가 변동 데이터를 신속하게 요청 후 갱신합니다.
- **상세 데이터 수치 제안**: 최고가/최저가 변동 스프레드율, 하루 대비 변동폭 수치를 시각적 화살표 아이콘과 매칭하여 실시간 시황 체감력을 극대화했습니다.
